# 万象星野（Critter Planet）— Web 3D 儿童互动动物星球

一款面向 4–10 岁儿童的全 3D 网页科普互动游戏：滑动旋转掌中的微缩星球，飞入不同自然生态小岛，观察自由活动的动物伙伴，点击听它们用中文语音做自我介绍，并预留了 **DeepSeek AI 自由问答与成本测试实验室**。

## 核心特性

- **全 3D 微缩星球视图**：360° 惯性拖拽旋转星球，4 大立体微缩生态地块（阳光草原、极地冰川、迷雾雨林、珊瑚海岸）+ 浮标提示 + 底部儿童快捷入口。
- **4 大 3D 生态箱庭 & 12 种关节动画动物**：
  - 阳光草原：非洲狮「阿雷」、长颈鹿「高高」、非洲象「嘟嘟」
  - 极地冰川：帝企鹅「团团」、北极熊「大白」、小海豹「圆圆」
  - 迷雾雨林：大熊猫「滚滚」、小树懒「慢慢」、巨嘴鸟「彩羽」
  - 珊瑚海岸：绿海龟「慢悠悠」、瓶鼻海豚「泡泡」、小海獭「敲敲」
- **动物自主行为 AI**：内置精力/饮食/玩耍轻量需求驱动，动物会自动漫步、前往水源喝水、去草地/竹林进食、打盹睡觉或玩耍，夜晚会更爱睡觉。
- **儿童友好语音互动**：点击动物平滑特写，自动播放中文语音自我介绍（Web Speech API）+ 玩具合成音效（Web Audio API）；提供「认识我 / 爱吃啥 / 看绝活 / 小秘密」、摸摸头、喂零食、真实 3D 拍立得拍照与动物图鉴。
- **预留 DeepSeek AI 对话与成本测试面板**：点击右上角 `⚙️ AI测试` 可填入 DeepSeek API Key，一键运行 3 轮儿童问答基准测试，实时统计缓存命中/未命中 Token、单轮费用与「1,000 儿童月成本预估」；未填 Key 时也可在本地模拟模式完整体验。
- **双轨 3D 资产管线**：默认内置零加载延迟的程序化 3D 萌系关节动物，并预留 `GLTFLoader` 热插拔接口，随时可用免费 CC0 `.glb` 模型无缝替换。
