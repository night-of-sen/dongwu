# 3D 模型、写实贴图与自然人声资产清单

本项目整合了 **6 大生态大陆板块**、**20 种 100% 写实高精动画 3D 动物**、**Poly Haven 摄影级 CC0 地表/岩壁贴图与户外 HDRI 天空**、**真实自然植物/珊瑚扫描模型**，以及 **120 条神经网络中文自然配音**，并全部做过 Web 端 512px 高清贴图压缩优化。

## 2. 写实环境贴图、HDRI、自然树木与水潭资产（CC0）

- **户外昼夜天空 HDRI**（`public/hdr/`）：Poly Haven `citrus_orchard_puresky`、`dikhololo_night`（CC0）
- **摄影级地表与岩壁 PBR 贴图集**（`public/textures/pbr/`，已优化压缩至 512px 极速加载）：Poly Haven `leafy_grass`、`snow_02`、`coast_sand_01`、`forest_floor`、`rock_face_01`（CC0）
- **Poly Haven 摄影级 3D 扫描自然地貌**（`public/models/polyhaven/`，CC0）：`fern_02`、`rock_moss_set_01`、`shrub_02`、`shrub_03`、`grass_medium_01`、`flower_gazania`、`tree_stump_01`、`dead_tree_trunk`、`namaqualand_boulder_02`、`quiver_tree_01`；水下珊瑚 `spined_sea_coral.glb`、`kelp_plant.glb`
- **写实自然树木与有机水潭**（`src/three/RealisticNature.js`）：弯曲树皮枝干 + 透明叶片/雪松针叶/羽状椰叶树冠（微风摇曳），以及不规则岸线水潭（水底鹅卵石床、河岸卵石群、荷叶睡莲/极地浮冰、芦苇草、菲涅尔焦散水波）

## 3. 自然神经网络中文语音资产

- 120 条预设故事/互动配音 MP3 位于 `public/audio/voices/`，由 [scripts/generate_voices.py](../scripts/generate_voices.py) 通过 Microsoft Edge 神经网络语音生成；
- AI 自由问答回复由 [vite.config.js](../vite.config.js) 内置 `POST /api/tts` 实时合成同声线自然人声。
